# Decentralized Communication-Efficient Fuzzy Neural Networks (DCENFNN)

This repository contains the core backbone code for the numerical experiments presented in the paper: 
**"Decentralized Communication-Efficient Fuzzy Neural Networks for Robust Cultural Semantics Modeling in National Image Analysis"** (Accepted by *Scientific Reports*).

## Overview

This repository provides the foundational custom code and mathematical algorithms used to generate the central results of our study. The code is divided into two main components covering both classification and regression tasks under our proposed decentralized framework.

## Repository Structure

*   📁 `classify-DCENFNN/`
    *   This directory contains models for the classification tasks using the proposed Decentralized Communication-Efficient Fuzzy Neural Network (DCENFNN). It demonstrates how the model captures robust cultural semantics in national image analysis.
*   📄 `iteration-regression and convex.py`
    *   This standalone script contains the core backbone implementation for the regression tasks and convex optimization iterations. All numerical regression experiments in the manuscript are built upon this algorithmic foundation.
